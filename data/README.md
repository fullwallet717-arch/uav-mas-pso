# Dataset

Place the following file in this directory before running the preprocessing script:

```text
data/yjmob100k-dataset2.csv
```

The dataset is not included in this repository.

| Column | Description |
|---|---|
| `uid` | User ID |
| `d` | Day index |
| `t` | Time-slot index |
| `x` | Horizontal coordinate |
| `y` | Vertical coordinate |

The current experiment uses day 0 and time slots 0 to 23.
